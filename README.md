# Portfolio — João Monteiro

Personal portfolio site focused on **AI Builder, software development, automation, data and Production Engineering**.
Static portfolio with no build step — `index.html` and a print-friendly `curriculo.html`, with **PT/EN language toggle**, light/dark themes, real portfolio project screenshots and a BASF automation impact panel (43 reports, 95.89% lower mean processing time).

🔴 **Live:** https://joaomonteirounesp.github.io/portfolio/

🔗 **Featured projects:** [5G research overview](https://github.com/JoaoMonteiroUNESP/JoaoMonteiroUNESP/blob/main/research/5g-sentinel.md) ·
[Driver Monitor](https://github.com/JoaoMonteiroUNESP/monitor-do-condutor) ·
[Financial Analysis](https://github.com/JoaoMonteiroUNESP/financial-analysis-dashboard) ·
[CasaOS](https://github.com/JoaoMonteiroUNESP/casaos-demo) ·
[Nos Labirintos do Eu](https://nos-labirintos-do-eu.vercel.app)

## Run locally

It's static: open `index.html` in a browser or serve the folder, including `curriculo.html`:

```bash
python -m http.server 8000
```

## Deploy

Already live on **GitHub Pages**. For **Vercel**: import the repo at [vercel.com/new](https://vercel.com/new),
choose Framework Preset **Other** (no build needed), leave *Build Command* and *Output Directory*
blank, and click **Deploy**.
